# Projeto 02 — Coluna jurídica

Projeto demonstrativo para preparar rascunhos de uma coluna semanal de revista especializada. Pauta, narrativa, nomes e situações são fictícios. O advogado autor deve revisar o texto antes de qualquer envio à redação.

## Estrutura

- `apoio/guia_estilo_revista.md`: formato, tom e limite editorial.
- `docs/protocolo.md`: instrução ao agente e entrada fictícia do teste.
- `docs/registro.md`: execução e verificação do resultado.
- `saida/`: rascunho da coluna.

Este material não valida teses jurídicas nem substitui pesquisa ou revisão profissional.
